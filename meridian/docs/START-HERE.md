# Meridian Assurance — start here

This kit is the complete handover for the Meridian assurance workbench used by MK Tron Group Internal Audit.

Meridian is an original evidence-to-assurance system. It is informed by publicly described reviewer-first audit practice. It is not Optro, not AuditBoard, and not a reconstruction of any vendor product.

## Read these in order

1. `USER-GUIDE.md` — user manual.
2. `DEPLOYMENT-AND-INTEGRATION.md` section A7 — how one-time passwords are issued. No password is stored in the kit.
3. `DEPLOYMENT-AND-INTEGRATION.md` — deploy and connect Claude, Gemini, and ChatGPT.
4. `INSTALLATION-GUIDE.md` — install commands.
5. `SETUP-GUIDE.md` — first-day setup.
6. `UPDATE-GUIDE.md` — update the app and the skill.
7. `KNOWLEDGE-TRANSFER.md` — memory, decisions, and data.
8. The full source is the git repository itself (`meridian/` folder).

The zip `meridian-gia-kit.zip` contains the same guides, the skill plugin, and the complete application source.

## Fastest way to use it today

1. Open the app.
2. Click **Connect AI**.
3. Paste a Claude API key or a ChatGPT API key and click Connect.
4. Open **Agent harness** and click **Run harness**.
5. Open **UAT evidence** to see the 32 checks.

A Claude.ai chat plan or ChatGPT Plus login is not an API key.

## Do not

- Paste a live API key into a link that other people can open.
- Load confidential evidence into a shared preview.
- Treat a model draft as an issued report.
- Treat a fraud indicator as a finding of fraud.
- Search for a skill or repository named `aibagent`. That word was a typo in an earlier note. It does not exist.
